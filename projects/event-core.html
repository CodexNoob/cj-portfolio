Event Core

Hall & event management SaaS platform for a New York-based client.

Event Core is a full-stack, multi-module SaaS platform I develop and maintain as a freelance full-stack developer (2026 – present). It runs the day-to-day operations of an event venue: bookings, calendar availability, event management, kitchen production, dining and seating, hall layouts, billing, reports, vendors, staff roles, permissions, and platform settings. Built with Next.js, React, TypeScript, Tailwind CSS, Supabase/PostgreSQL, and Playwright, and deployed through GitHub, Vercel, and Netlify.

Modules & workflows

  • Bookings & Calendar — booking creation and management with calendar availability checks across halls and dates.
  • Event Management — event details, schedules, and status tracking tied to bookings.
  • Kitchen Operations — menu selection and kitchen-only production jobs so kitchen staff see exactly what to prepare.
  • Dining & Seating — Dining Manager for table assignments and seating plans.
  • Hall Layouts — Hall Room Map with reusable hall presets for fast setup of recurring configurations.
  • Billing & Reports — billing records and operational reports for management.
  • Vendors, Staff & Permissions — vendor records, staff roles, and role-aware workflows that limit what each user can see and do.
  • Platform Settings — configuration screens for venue-level defaults.

Engineering notes

  • Implemented authentication flows, CRUD operations, form handling, PostgreSQL persistence, and role/permission concepts on Supabase.
  • Built responsive operational dashboards that work on both desktop and mobile for on-site venue staff.
  • Used Playwright to validate critical flows — mutation, persistence, menu-selection, and dashboard interactions — before merging.
  • Translated client conversations and real venue-operation requirements into implementation plans, UI behavior, and workflow decisions.
  • Collaborated through GitHub branches, pull requests, commits, and merges with hosted deployments on Vercel and Netlify.
  • Used ChatGPT, OpenAI Codex, Claude, and Base44 to accelerate prototyping, debugging, refactoring, and test generation, while personally reviewing and validating all production code.

Project role

Sole full-stack developer working directly with the client — responsible for implementation, testing, troubleshooting across frontend, backend, database, and deployment, and ongoing feature delivery.

Platform Interfaces

Kitchen Calendar

Weekly kitchen production view with a column per day, Today and Shabbos highlighting, quick-add kitchen events, worker management, and a filter to show only the signed-in staff member's assigned items.

Menu Library

Menu management with a searchable item library, category badges, bulk upload, and separate tabs for packages, buffet, plated, and drink menus plus add-ons, feeding the kitchen-only production jobs.

Tech Stack

Frontend

Next.js and React with TypeScript, styled with Tailwind CSS in a component-based architecture. Responsive layouts for desktop dashboards and mobile use on the floor.

Backend & Data

Supabase with PostgreSQL for authentication, persistence, and role-aware data access. CRUD workflows, forms, and operational management screens backed by real database state.

Testing & Delivery

Playwright end-to-end tests for mutation and persistence flows; Git/GitHub branching and pull requests; hosted deployments on Vercel and Netlify.
