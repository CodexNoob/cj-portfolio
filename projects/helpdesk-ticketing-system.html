HelpDesk Ticketing System

A support ticketing app for users, support teams, network teams, and admins.

This project is a React and Supabase helpdesk workflow built for portfolio use. It lets users request access, submit tickets, track their own requests, and continue conversations through ticket comments and screenshot attachments.

The admin side focuses on support operations: reviewing account requests, assigning tickets, filtering the queue, changing status and priority, and maintaining activity history across each ticket.

What's included

  • Email and password authentication through Supabase.
  • Role-based dashboards for users, admins, support team members, and network team members.
  • Ticket creation, assignment, status changes, priority updates, comments, and activity logs.
  • Search and filtering by status, priority, ticket content, user, and assigned team.
  • Screenshot attachment support using a Supabase storage bucket.
  • Account request approval flow backed by a Supabase Edge Function.

Database and security

The schema uses Supabase tables for profiles, tickets, account requests, knowledge base entries, and storage objects. Authenticated Row Level Security policies keep users limited to their own tickets while support and admin roles can manage queue-level work.
